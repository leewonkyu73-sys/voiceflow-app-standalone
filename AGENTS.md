# VoiceFlow repository instructions

For every code, UI, STT, translation, meeting, CI, or deployment change in this repository:

1. Read and apply `.codex/skills/voiceflow-change-ledger/SKILL.md`.
2. Read the relevant entries in `.codex/skills/voiceflow-change-ledger/references/ledger.md` before editing.
3. Do not add peripheral features while voice input → original text → target translation is failing or unverified.
4. Update the ledger with evidence-based success, failure, rollback, and remaining device verification before completing the task.
5. Never record credentials, tokens, private audio, or customer data in the ledger.
