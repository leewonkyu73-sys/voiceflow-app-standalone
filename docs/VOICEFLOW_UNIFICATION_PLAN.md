# VoiceFlow 통합 기준 (운영본 우선)

## 단일 기준

- 최종 운영 URL: https://voice.star45.net
- 최종 운영 저장소: leewonkyu73-sys/voiceflow-smart-workspace
- 통합 작업 브랜치: integration/voiceflow-unified-v14
- GPT Sites의 VoiceFlow UI Check v14는 기능·UI 참고본으로만 유지한다.
- 운영 main, DNS, 데이터, Secret, Provider 설정은 통합 검증 전 변경하지 않는다.

## 반드시 보존할 운영 기능

- 회원가입·로그인·계정삭제·관리자 회원관리
- 음성 및 영상 녹화 진입
- 실시간 원문·번역 병기와 Translation Assurance
- 회의방, 링크·NFC 초대, AI 직원 초대와 미션
- 일정, 자연어 업무 등록, 자료실
- 관리자 Provider·Integration·진단 UI
- VPS/nginx/Docker/CI 배포 경로와 기존 API /api/v1/*

## UI Check v14에서 이관할 기능

1. 회의 메뉴를 누르면 방 진입 없이 개인 녹음기로 즉시 시작
2. 초대 후에만 회의·상담 모드로 전환
3. 녹음 일시정지·계속·종료
4. 입력창 옆 초대·종료·전송, 입력창과 하단 내비게이션 밀착
5. 녹음 품질을 작은 상태표시로 제공: 입력 레벨·노이즈·클리핑
6. 말하는 언어 설정은 채팅에서 숨기고 설정에 배치
7. 종료 후 임시 검토 → 저장하지 않기 또는 확인 후 저장
8. 원문·번역 병기, 숫자·이름·문장길이 기반 번역 오류 확인
9. 회의 요약·결정·할 일 편집 → 확인 → 저장·공유
10. 음원 볼륨 증폭·음성 외 노이즈 감소·음악 제거 선택
11. 원본은 중앙 보관하고 일반 사용자는 목록 숨김만 가능
12. 최고관리자 원본 복사·보관함 이동·삭제 및 감사기록
13. 오프라인 업로드 대기·재시도 상태
14. PC·스마트폰 PWA 설치 안내

## 통합하지 않을 항목

- UI Check 전용 샘플 문구와 가짜 성공 상태
- 브라우저 localStorage/IndexedDB를 운영 원본의 최종 저장소로 사용하는 방식
- 운영 API를 D1/R2로 교체하는 작업
- 기존 데스크톱 UI 전체 교체

## 구현 순서

1. 기존 /api/v1 데이터 모델과 녹음 저장 엔드포인트 재사용 여부 확인
2. 녹음 화면에 v14의 간결한 컨트롤과 상태 표시만 이식
3. 일시정지와 임시 폐기 플로우 연결
4. 종료 후 정리·편집·확인·저장·공유 화면 연결
5. 최고관리자 원본 관리와 감사기록을 기존 인증·권한 체계에 연결
6. 데스크톱·390px 모바일·PWA·마이크 거부·오프라인 재시도 검증
7. 테스트 통과 후 PR 검토, 이후에만 main 병합·VPS 배포

## 완료 게이트

- 기존 로그인·영상·일정·업무·자료·NFC·AI 직원 기능이 유지된다.
- 음성 녹음 시작·일시정지·계속·종료가 실제 MediaRecorder로 동작한다.
- 원문과 설정 번역문이 동시에 표시된다.
- 저장하지 않기를 선택하면 서버 원본이 생성되지 않는다.
- 저장한 원본은 재접속 후 조회된다.
- 일반 사용자의 원본 삭제가 서버에서 거부된다.
- 최고관리자 작업은 감사기록에 남는다.
- 운영 main과 DNS는 승인 전 변경되지 않는다.
